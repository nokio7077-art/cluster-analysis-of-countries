## 📌 О проекте

Проект исследует, образуют ли страны естественные социально-экономические группы (например, бедные аграрные, развивающиеся, индустриальные, богатые развитые), опираясь только на количественные показатели развития — без меток, без предположений о регионе или континенте.

Реализованы, настроены и сопоставлены друг с другом три алгоритма кластеризации:

| Метод | Как выбирается число/форма кластеров |
|---|---|
| **Иерархическая (метод Уорда)** | Анализ дендрограммы + поиск резкого скачка расстояний ("колено") |
| **K-Means** | Метод локтя по инерции, сравнение случайной инициализации и `k-means++` |
| **DBSCAN** | `eps` подбирается автоматически по графику расстояний до k-го соседа с поиском "колена" (Kneedle) |

Качество кластеризации проверяется метриками **Silhouette**, **Calinski-Harabasz** и **Davies-Bouldin**, а результаты визуализируются в 2D с помощью **PCA** и **MDS**.

## 🗂️ Датасет

- **Источник:** Статистический отдел ООН — *World Statistics Pocketbook* ([`country_profile_variables.csv`](data/country_profile_variables.csv), 229 стран × 53 показателя)
- **Очистка:** значения-заглушки `-99` преобразуются в `NaN`; строки с пропусками в признаках для кластеризации удаляются → остаётся **186 стран**
- **Признаки для кластеризации** (нормализованы Min-Max):
  - ВВП на душу населения (текущие US$)
  - Плотность населения (чел./км²)
  - Уровень безработицы (% рабочей силы)
  - Суммарный коэффициент рождаемости (детей на женщину)
  - Городское население (% от общего)
  - Уровень детской смертности (на 1000 живорождений)

Подробности — в [`data/README.md`](data/README.md).

## 🔬 Методология

1. **Загрузка и очистка** данных ООН, исправление названия колонки с детской смертностью, обработка кодов пропусков `-99`
2. **Отбор признаков и Min-Max нормализация** шести показателей выше
3. **Иерархическая кластеризация (метод Уорда)** — построение полного дерева объединений, усечённая дендрограмма, выбор `k=5` по графику скачков расстояний
4. **K-Means** — перебор `k = 1..10`, сравнение случайной инициализации и `k-means++` методом локтя, финальная модель при `k=5`
5. **Кросс-валидация** иерархической кластеризации и K-Means через тепловую карту сопряжённости (согласованность 84–95% для 4 из 5 кластеров)
6. **Профилирование кластеров** — среднее/стандартное отклонение по каждому признаку, boxplot'ы для оценки разброса и выбросов внутри кластеров
7. **Снижение размерности** — проекция кластеров в 2D методами PCA (78.1% объяснённой дисперсии) и MDS для визуальной проверки
8. **DBSCAN** — оценка `eps` по графику k-го соседа (поиск "колена"), перебор параметров и демонстрация того, почему плотностная кластеризация не работает на этом непрерывном признаковом пространстве
9. **Количественное сравнение** всех трёх методов по метрикам внутренней валидации

## 📊 Результаты

| Метод | Silhouette ↑ | Calinski-Harabasz ↑ | Davies-Bouldin ↓ |
|---|---|---|---|
| **K-Means (k=5)** | **0.307** | **114** | **1.057** |
| Иерархическая (Уорд, k=5) | 0.244 | 94 | 1.185 |
| DBSCAN | -1.00* | -1* | -1* |

\* *DBSCAN сводит весь датасет к одному кластеру (плюс шумовые точки) во всём протестированном диапазоне параметров — это свидетельствует о том, что показатели развития стран образуют **континуум** (постепенный переход от бедных к богатым), а не плотные, чётко разделённые группы. Это само по себе содержательный результат, а не неудача метода.*

**Главный вывод:** K-Means и иерархическая кластеризация согласуются по 4 из 5 кластеров, выделяя узнаваемые социально-экономические уровни (высокоразвитые страны с высоким доходом, индустриализирующиеся экономики, страны с переходной/средней экономикой и менее развитые аграрные страны); основное расхождение приходится на переходную группу стран с доходом выше среднего.

## 🚀 Быстрый старт

```bash
git clone https://github.com/nokio7077-art/cluster-analysis-of-countries.git
cd cluster-analysis-of-countries

python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt

jupyter notebook notebooks/cluster_analysis.ipynb
```

Ноутбук читает `data/country_profile_variables.csv` — запускайте ячейки по порядку сверху вниз.
